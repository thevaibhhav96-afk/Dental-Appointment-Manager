# O'dent Dental Clinic — Smart Appointment Management System

## Project Title

O'dent Dental Clinic — Smart Appointment Management System

## Overview

A simple Python console application for managing dental clinic appointments. The system allows users to manage patients, dentists, appointments, follow-ups, and basic clinic statistics.

## Features

- Add and search patient records
- Add and view dentist information
- Book, cancel, and reschedule appointments
- Check dentist availability
- Detect appointment conflicts
- Manage patient follow-ups
- Track appointment status
- Generate basic clinic statistics
- Beginner-friendly Python implementation

## Algorithms Used

- Linear Search
- Counting
- Maximum and Minimum
- Duplicate Detection
- Appointment Conflict Detection
- Dentist Availability Check
- Follow-up Checking
- Input Validation

## Technologies / Tools Used

- Python 3.x
- VS Code
- GitHub
- No external libraries required

## Steps to Install & Run

1. Ensure Python 3 is installed.
2. Clone the repository or download the project files.
3. Open Terminal / Command Prompt.
4. Navigate to the project folder.
5. Run the Python program.
